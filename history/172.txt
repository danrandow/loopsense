OpenClaw Loopy adapter (new directory and files)

WHY:

LoopSense is moving from manually started Claude sessions to an always-on OpenClaw runtime. The agent identity, bootstrap instructions and operating guidance are part of the LoopSense product and therefore need to be versioned in the public repository. Runtime credentials, sessions and mutable OpenClaw state must remain outside Git.

This adapter makes Loopy portable to OpenClaw without duplicating the canonical Loopy methodology. It also addresses a failure observed during the migration: treating historical retrospectives and stale notes as current state. The adapter requires reconciliation against current authoritative files and explicit separation of workflow completion, experiment completion, hypothesis outcome and iteration closure.

SCOPE:

- openclaw/README.md
- openclaw/agents/loopy/AGENTS.md
- openclaw/agents/loopy/SOUL.md
- openclaw/agents/loopy/IDENTITY.md
- openclaw/agents/loopy/USER.md

BEFORE:

(files and directories did not exist)

AFTER:

A minimal repo-owned OpenClaw adapter exists for Loopy. It points to agents/loopy for canonical instructions, identifies Dan using approved public information only, defines evidence-first current-state reconciliation, and documents the boundary between versioned product files and non-versioned runtime state.
