## Approach: comment first, not broadcast

**Why**: A thread nobody sees is noise. A comment on an existing conversation where practitioners
are already feeling the problem is signal. Comment first, collect verbatims, learn what language
they use, then post the thread using their words.

## Step 1 — Find the threads

Search X, LinkedIn, HN for active practitioner conversations about:

- Multi-agent systems and output quality
- Agent orchestration for knowledge work
- "How do I know if my AI agent is any good"
- LangGraph / CrewAI / AutoGen + product / PM / research
- "AI agents for product discovery / roadmap / research"

Look for threads with genuine practitioner engagement — not hot takes, but people who've tried
something and are describing what happened.

## Step 2 — Comment with questions that surface the problem

Use these questions (Dan's framing, Sep 2026):

- How real is this problem — specifics?
- Has anyone found a solution?
- What has been tried?
- How come the patterns that work for code don't work here?
- What specific failures have occurred?
- How much work goes into writing the tests and is it worth it?
- What are the parallels and differences compared with code loops?
- Who has tried graph topologies that adapt to the situation? How is that going?

**Tone**: Curious practitioner, not promoter. Ask what they're finding. Don't mention Randow Maps yet.

## Step 3 — Capture verbatims

Any reply that names a specific failure, a workaround, or a "yes exactly" goes straight into
`agents/gtm/knowledge/gtm-v0.md` under Practitioner signals. Handle, platform, date.

## Step 4 — Post the thread only when

- At least 3 verbatims captured from real practitioners
- At least 1 practitioner who clearly fits ICP (has shipped code agents, is now doing product work)
- The thread opening uses language from verbatims, not our own framing

## What the thread is (when ready)

Self-referential problem-frame. "What if your product pipeline was an agent team?"
The pipeline built this thread. That's the honest version of dogfooding.
See `knowledge/what-if-thread-draft-v0.md` for draft.

## Kill signal

If comments get zero engagement (not even a "no that's not my experience"), the problem framing
is wrong or the audience is wrong. Update the bet before posting the thread.

## What the daily research task does

Searches for practitioner verbatims every day (about 8am NZ). Fills `agents/gtm/knowledge/gtm-v0.md`.
The more cycles run, the better the thread will be. But don't let perfect be the enemy of first.
