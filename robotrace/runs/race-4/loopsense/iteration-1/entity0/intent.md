The design uses a symmetric sensor array with five sensors: three front-facing sensors spaced evenly across the front width to detect the path ahead and two additional sensors slightly behind and centered laterally to improve line detection and reduce line loss events. The sensor size is moderate to balance resolution and noise robustness. The wheel track is set wide within bounds to improve stability and reduce steering oscillations. The body dimensions and mass are chosen conservatively to maintain stability and allow for effective control. This geometry aims to improve path tracking accuracy, reduce line loss events, and stabilize steering control as indicated by the integration feedback.
