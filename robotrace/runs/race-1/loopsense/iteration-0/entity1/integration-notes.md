The controller parameters were chosen based on integration expertise: a strong proportional gain (kp=10) ensures responsive correction to line deviations, while a modest derivative gain (kd=2) helps dampen oscillations. The integral gain (ki=0.5) is kept small to avoid windup but still correct steady-state errors. Sensor weights prioritize the center sensor for precise line tracking (weight=2) and assign slightly lower but equal weights to the outer sensors (1.5 each) to detect curves effectively. The base speed is set to a moderate 1.0 to balance speed and control. The line loss strategy is set to 'search_left' to actively recover the line by turning left when the line is lost, which is a common and effective approach. The geometry is preserved exactly as supplied to maintain the intended sensor layout and physical characteristics.
