## Randow Maps

Randow Maps are a core representation used by Loopsense and the robotrace experiment. Before analysing, creating, or modifying any Randow Map YAML in this repository:

1. Read `/Users/danrandow/github/randow-maps-authoring/skills/randow-maps-authoring/SKILL.md` completely and follow it as the canonical authoring method.
2. Read `/Users/danrandow/github/randow-maps/docs/schema.yaml` completely and treat it as the canonical data-schema reference.
3. Follow repository-specific experiment and storage instructions where they are more specific; do not assume that a map belongs in the external `randow-maps-data` repository merely because the general authoring skill uses that default.

Do not author Randow Map YAML from memory. Preserve the authoring skill's topology/scenario distinction, closed-loop discipline, evidence and confidence rules, measurement model, ID conventions, and validation checklist.
